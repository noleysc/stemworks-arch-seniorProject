Project: STEMWORKS Dashboard for JadeFlowers  
Part 3: Technology  
CEN 4934

Stemworks is a web-based business management platform being developed for Diaz Ventures LLC. The goal of the system is to bring business operations, customer relationships, event management, and financial reporting into one platform. Although Stemworks is being developed from scratch, it will need to work with existing third-party services such as Shopify, Airbnb, and Square, depending on the business. These services already help businesses manage activities such as bookings, payments, and sales. However, using several systems at once can make it difficult for owners to track important information without switching between different websites. Stemworks aims to solve this problem by bringing that information into one dashboard while keeping each business's operations and customer data separate.

The technical specifications provided by Samantha Diaz recommend Next.js, React, and TypeScript for the user interface, Node.js with Express for backend development, and PostgreSQL for storing business information. Tailwind CSS is planned for styling, Prisma for database access, and services such as Vercel and Supabase for hosting. In the current GitHub implementation (`noleysc/stemworks-arch-seniorProject`), the team is delivering that stack as a modular Next.js 14 application with API route handlers, Prisma for schema access, SQLite for local development, and Supabase as the hosted PostgreSQL target. Stripe is used for ticket payments when configured; without keys, checkout runs in demo mode. These technologies were chosen because they are widely supported, have extensive documentation, and can support a web application used across desktop and mobile devices.

Each technology offers different advantages and limitations. React allows us to build reusable interface components, while Next.js provides tools for organizing the application and handling requests. TypeScript helps identify certain coding errors during development. PostgreSQL is suitable for storing structured information such as appointments, customers, and transactions, while Prisma simplifies communication with the database. Tailwind CSS supports consistent styling across desks (rentals, Jade Flowers, Pampered Soul, and the founder dashboard). However, using several technologies together adds complexity, and team members must understand how their components interact. Managed hosting services also reduce the need to maintain physical servers, although they introduce ongoing service dependencies and possible costs as usage increases. Local SQLite speeds early slices, but the production path remains PostgreSQL with row-level isolation between tenants.

One important constraint is that Stemworks must work alongside the software businesses already use without forcing them to change their existing workflows. We will need to determine which services provide access to their data and what integration options are available. For example, rental data is collected through desk entry and CSV import rather than scraping Marriott or Airbnb pages, and Stemworks does not replace a hotel property management system. Another requirement is keeping customer and financial information separate between businesses (Luminary, Diaz Ventures / Jade Flowers, and Pampered Soul). The system will therefore need appropriate user permissions and database access controls to prevent unauthorized access. Confirmed and Potential totals never sum across tenants.

Potential challenges include unreliable connections to third-party services, changes to external APIs, growing amounts of business data, and maintaining the application as additional businesses are added. To reduce these risks, we plan to test integrations before relying on them, handle connection failures appropriately, and verify that users can access only the information they are authorized to view. We will also prioritize the essential features needed for the initial working version before expanding the system—as shown in recent `main` commits that shipped ticketed invites, client booking, calendars, Jade batch tracking, and free-ticket checkout as contained slices. The technology stack may be adjusted as development continues, but any significant changes will be discussed with the team and sponsor before implementation.
